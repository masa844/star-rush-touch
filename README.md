# Star Rush: Touch Overdrive

スマホでもPCでも遊べる、HTML / CSS / JavaScriptだけで作った縦スクロールシューティングゲームです。

昔ながらのアーケード系シューティングをベースにしつつ、強力な武器を無制限に切り替えて大量の敵を倒していく、爽快感重視のゲームになっています。

## Demo

https://masa844.github.io/star-rush-touch/

## Features

- スマートフォン / PC対応
- 攻撃は完全オート
- 9種類の攻撃モードをいつでも切り替え可能
- 敵弾を破壊できる強力な特殊攻撃
- ステージ進行に合わせて敵の物量が大幅に増加
- ステージ終盤にはHPゲージを持つボスが出現
- 自機は大容量HP制で、気軽に遊べる難易度
- スコア表示あり
- セーブ、ランキング、データ保存なし
- ビルド不要・外部ライブラリ不要

## Controls

### Smartphone

- 画面をタップ：タップした位置へ移動
- `TAP / SPACE` ボタン：攻撃モード切り替え
- 攻撃：オート

### PC

- 画面をクリック：クリックした位置へ移動
- `Space`：攻撃モード切り替え
- 画面上の `TAP / SPACE` ボタンでも切り替え可能
- 攻撃：オート

### PC Hidden Shortcuts

PCでは数字キー `1`〜`9` で攻撃モードを直接切り替えられます。`Space` による順番切り替えもそのまま使用できます。

| Key | Weapon |
| --- | --- |
| `1` | `SHOT` |
| `2` | `HEAVY` |
| `3` | `WIDE` |
| `4` | `BIG BANG` |
| `5` | `LASER` |
| `6` | `SPIRAL` |
| `7` | `HOMING` |
| `8` | `FIREWORK` |
| `9` | `BUSTER` |

## Weapons

| Mode | Description |
| --- | --- |
| `SHOT` | 正面へ高速連射する基本ショット |
| `HEAVY` | 大型弾を正面へ発射。敵弾を破壊しながら進む |
| `WIDE` | 前方の広い範囲へ扇状に連射。敵弾も破壊可能 |
| `BIG BANG` | 大型弾が画面中央付近で爆発し、画面内の敵を一掃する |
| `LASER` | 高速レーザーを正面へ連射する高火力モード |
| `SPIRAL` | 弾数・角度・速度・色・曲がり方がランダムに変化する渦状攻撃 |
| `HOMING` | 敵と敵弾を自動ロック。敵数に応じて同時発射数と連射速度が上昇する迎撃型ホーミング |
| `FIREWORK` | 360度へ弾を放ち、離れた位置で各弾がさらに全方向へ炸裂する全方位攻撃 |
| `BUSTER` | 自機を中心に太い赤色レーザーが反時計回りに1秒で1回転。敵弾を消し、通常敵を掃討する |

## Game Flow

敵編隊を倒しながら宇宙空間を進み、一定時間ごとに出現するボスを撃破すると次のステージへ進みます。

ステージが上がるにつれて敵の出現数が急激に増えていきますが、それに対抗できる強力な攻撃モードを自由に使える設計です。

ゲームオーバーになっても、その場ですぐ最初から再開できます。スコアや進行状況は保存されません。

## Run locally

`index.html` をブラウザで直接開くだけでプレイできます。ローカルWebサーバーやインストール作業は不要です。
